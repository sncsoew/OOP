Detailed Description

Представляет гостиничный номер.

Класс хранит информацию о номере, этаже, стоимости проживания, состоянии занятости и текущем госте.

Класс обеспечивает проверку корректности номера, этажа и цены, а также операции заселения и выселения гостей.

Warning
Номер комнаты и цена должны быть положительными.
