Detailed Description

Класс для работы с обыкновенными дробями.

Класс позволяет создавать дроби, выполнять арифметические операции, сравнивать дроби, изменять их значение с помощью инкремента и декремента, а также выводить их в поток.

Дробь представляется числителем и знаменателем. Функция normalize() используется для приведения дроби к сокращённому виду и проверки корректности знаменателя.

Warning
Знаменатель дроби не должен быть равен нулю.
